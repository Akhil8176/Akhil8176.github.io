State● Resolved
CategoryAI / Automation
Assigned toAkhil Yadati

An agent that detects system issues, opens incidents in ServiceNow through the Table API as a least-privilege integration user (itil role), triages them with an LLM using the instance's own categories and groups, and writes its reasoning into the work notes. Critical or uncertain calls are held for a human.

What testing found: on 300 IT tickets the model looked worse than guessing on priority. A blind two-rater audit (kappa 0.73–0.92) showed the benchmark labels were near-random — the model matched both human raters 80–95% on type and priority. Assignment group was the real gap; giving the model the raters' team definitions lifted it from ~54% to 67–75%, and the rest traced to missing caller/CI context.
